# CRM & Business Intelligence Coursework 2

## Overview

Coursework 2 focused on using Python and data analysis techniques to investigate Amazon stock performance and explore data-driven change management in the FinTech industry.

## Key Areas

* Python-based financial data analysis
* Stock price visualisation and technical indicators
* Linear Regression and Random Forest modelling
* Model evaluation and prediction
* FinTech and data-driven change management
* Predictive analytics and intelligent finance

## Technologies

* Python
* Google Colab
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook
